# OpenSpec files

`openspec/specs/<area>/<capability>/spec.md` = current behaviour (Requirement + `#### Scenario:`); `openspec/changes/<id>/` = work in flight (`proposal.md`, `design.md`, `tasks.md`, delta specs). A change with no delta declares `skip_specs: true` in its `.openspec.yaml`. `.claude/commands/opsx/**` and `.claude/skills/openspec-*/**` are generated by the CLI, never hand-edited. → `docs/conventions/openspec-workflow.md`
